The audio mixer's `volume-x.svg` and launcher's `search.svg` are also from Lucide tag `0.468.0`, under the same retained ISC/Feather license.

Home's `wifi.svg` and `bluetooth.svg` use Lucide tag `0.468.0` under the same retained license.

The Home sidebar and quick-tile additions `circle-dot`, `monitor`, `activity`, `gamepad-2`, `cloud-sun`, `calendar-days`, `bell`, `bell-off`, `mic`, `coffee`, `moon`, and `leaf` are unmodified SVGs from the same Lucide tag `0.468.0` and retained license. The reference shell's logo and avatar are not bundled.

The activity notch's `chevron-right`, `timer`, and `download` SVGs also use Lucide tag `0.468.0` with the same retained license.

The bar's GPU `circuit-board.svg` uses the same Lucide tag `0.468.0` and retained ISC/Feather license.

The System GPU legend's `memory-stick.svg`, `thermometer.svg`, and `zap.svg` also use Lucide tag `0.468.0` and the same retained license, alongside the existing `activity.svg`.

Window-management and clipboard icons `panels-top-left.svg`, `pin.svg`, `clipboard.svg` and `eye.svg` use the same tag and retained license. Screenshot Manager's `scissors.svg` and Home's `house.svg` also use that pinned tag and license.

The lock-preview toolbar uses `lock-keyhole.svg` from Lucide 0.468.0 under the same retained ISC license.

`fold.png`, `orbit.png` and `steps.png` are original geometric fixtures, generated by `tools/generate_wallpapers.py`. Regenerate with `uv run tools/generate_wallpapers.py`. No artwork from reference screenshots is bundled.

PySide6 6.8.3 and matching Qt/Shiboken development packages are pinned by `pyproject.toml` and `uv.lock`. The virtual environment is excluded from source control. Review upstream Qt/PySide6 LGPL/GPL/commercial terms before redistributing a bundled runtime; production is intended to run under Quickshell.
